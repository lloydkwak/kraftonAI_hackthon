# Method

Each episode is one released 2-1 replay (`data/released.npz`, the same name) driven in the reference environment with the camera on; there is no guide vessel in the scene. Frames every 0.5 s from t = 0; `ego_motion` is the log's measured surge, sway and yaw rate at the same instants (zero at t = 0, the rest state); `action` is the command in force over the next 0.5 s; `actuator_state` is that command with the azimuth clipped -- the reference's actuator feedback is withheld. Each replay ran in a weak constant water current of its own (see data/manifest.json), which the frames show as the scene drifting. The commands are 2-1 excitation sequences. `d_target` is the format's default and means nothing here. Appearance is one draw per episode from the reference camera's day model on a day assigned by design: every weather at severity 1.0 and 1.35, two light days (0.5) and two clean ones (0), in the manifest's `day` and `severity`. This is calibration data seen through the reference camera; the 2-2 training set is the participant's own dataset.
